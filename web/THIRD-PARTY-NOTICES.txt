THIRD-PARTY NOTICES — sonic2 (Sonic the Hedgehog 2, s2disasm)
===========================================================

No ROM, and no bytes extracted from a ROM, are present in this repository or in the
page it publishes. The page runs whatever Mega Drive ROM the person loads from their
own disk: it is read with the File API, handed to the emulator core in page memory,
and never sent anywhere.

(This file is .txt, not .md, on purpose: ".md" is both the Markdown extension and the
Mega Drive ROM extension, and .gitignore excludes *.md as a ROM type.)

3. NOT INCLUDED
---------------

Nothing from EmulatorJS, Genesis Plus GX or PicoDrive is distributed, linked or
fetched by this page. An earlier version of the page used EmulatorJS with the
genesis_plus_gx core; both were removed on 2026-10-05 because Genesis Plus GX and
PicoDrive both carry "Redistributions may not be sold, nor may they be used in a
commercial product or activity", which is not an open-source licence.

Genesis Plus GX was built locally, outside this repository, purely as a test oracle
to measure mdcore's output against. It is not shipped, not linked, and not required
to build or run anything here.
