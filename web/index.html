Sonic 2 — Keys: Arrows move · Z / X / C A / B / C (any jumps) · Enter Start

Sonic the Hedgehog 2 (Mega Drive)

Runs the ROM you built from the sonicretro/s2disasm disassembly — or your own cartridge dump.

Your file never leaves this machine. The File is handed straight to the emulator core (mdcore, MIT licence) in page memory — no upload, no copy into IndexedDB, no server side to this page. Every off-origin request is blocked outright (the console lists any that were attempted), so the page cannot talk to anything but the host it came from.

Sound is on once the game starts. The Sound button below the game turns it off.

The sonicretro/s2disasm disassembly reassembles this cartridge byte for byte (Rev B from its classics branch, REV01 from master).
